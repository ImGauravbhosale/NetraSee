# NetraSee frontend

Next.js 16 (App Router) + TypeScript + Tailwind. See the [project README](../README.md)
for what NetraSee is, and the [user guide](../docs/USER_GUIDE.md) for how to use it.

## Dev server

```bash
npm install
npm run dev
```

Needs the backend running at `NEXT_PUBLIC_API_BASE_URL` (defaults to
`http://localhost:8000`) — see [`../backend`](../backend).

## Build

```bash
npm run build
```
